01The problem

The MCP works. Claude using it well is the hard part.

→ Connection

MCP connects unreliably in Excel

Tool discovery is cached and partial at conversation start. Claude often sees fewer than half the available tools.

→ Protocol

Tools have strict rules Claude misses

Mandatory ping. Mandatory validate_and_fix_sql before execute_sql. Module classification on every investigate. Easy to skip.

→ Output

Responses don't fit the Excel sidebar

Long prose, missing citations, no evidence tiering. Tables that won't paste into cells. Hedging where data doesn't exist.

03What's in the protocol

A skill that knows what good looks like.

  1. / 01

    Bootstrap before answering

    Multiple varied tool_search queries warm the VGPT MCP connector silently before any work begins. Caps at 3 attempts—no infinite loops.

  2. / 02

    Enforce the documented MCP protocol

    ping mandatory. search_guides before investigate. modules and concepts classified on every call. SQL through validate_and_fix_sql before execute_sql, always.

  3. / 03

    Evidence tiers on every claim

    Each statement labeled [DOCUMENTED], [SCHEMA], or [NOT-DOCUMENTED]. Hedging words banned. KB articles cited by title and number.

  4. / 04

    Triage the 20+ response_guidelines

    Classifies the question type (documentation / reporting / reconciliation / security) and applies only the relevant subset. No bloated answers stuffed with sections that don't apply.

  5. / 05

    Format for the spreadsheet sidebar

    Lead with the answer. Clean markdown tables with no merged cells. SQL in fenced blocks. Compact citations at the end. No long prose.

  6. / 06

    Handle known quirks

    De-duplicates repeated entries in intelligence_findings. Falls back to behavioral_warnings when business_purpose is empty. Distrusts tables_used in favor of the actual SQL FROM clause.
